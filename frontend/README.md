# 🎨 E-Commerce Frontend

This is the frontend of the E-Commerce application built using **React.js** and **Tailwind CSS v3**.

The frontend consumes REST APIs from the backend and provides a responsive, modern user interface.

---

## 🧱 Tech Stack

- React.js
- Tailwind CSS v3
- Redux Toolkit
- React Router
- Axios
- Socket.io Client

---

## 📂 Folder Structure
```bash
src/
├── components # Reusable UI components
├── pages # Page-level components
├── redux # Redux store & slices
├── services # API calls
├── hooks # Custom hooks
├── utils # Helper functions
└── App.jsx
```

---

## 🎯 Features

- Authentication pages (Login/Register)
- Product listing & details
- Cart & wishlist UI
- Order tracking
- Admin dashboard
- Responsive design with Tailwind

---

## 🚀 Running the Frontend

### 1. Install dependencies
npm install
### 2. Start development server
npm run dev
